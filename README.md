# omnivoice-rewrite

Голосовое сообщение → расшифровка → правка текста у языковой модели → та же
история, но переписанная, **твоим же голосом**.

Три шага собраны в одну команду, но каждый можно вызвать и отдельно:
`transcribe`, `edit`, `say`.

- **Голос** клонирует [OmniVoice](https://github.com/k2-fsa/OmniVoice) (k2-fsa,
  600+ языков, zero-shot по образцу 3–10 секунд, 0.6B параметров). В bfloat16
  ему хватает 2–4 ГБ видеопамяти, в fp32 — 8–12 ГБ. На 4 ГБ и меньше модель
  уезжает в системную память и считается как процессор: работает, но медленно.
- **Расшифровка** — `faster-whisper` локально, никуда ничего не отправляется.
- **Правка** — любая LLM: DeepSeek, Moonshot, Gemini, OpenAI или своя Ollama.
  По умолчанию DeepSeek.

## Установка

Windows, PowerShell (одной строкой):

    py -m pip install torch torchaudio --index-url https://download.pytorch.org/whl/cu124

    py -m pip install -r requirements.txt

Linux или macOS — то же самое, только `python3 -m pip` вместо `py -m pip`.
Для видеокарт NVIDIA подставь свою версию CUDA в ссылку (`cu124`, `cu128`).

Проверка, что всё встало:

    python rewrite.py --help

## Настройка ключа

Ключ берётся из переменной окружения, в командной строке его держать не надо.

PowerShell:

    $env:LLM_PROVIDER="deepseek"; $env:LLM_API_KEY="твой-ключ"

Linux или macOS:

    export LLM_PROVIDER=deepseek LLM_API_KEY=твой-ключ

Переменные: `LLM_PROVIDER` — `deepseek`, `moonshot`, `gemini`, `openai`,
`ollama` или `none` (тогда править не надо, текст пойдёт как есть);
`LLM_API_KEY` — ключ; `LLM_BASE_URL` и `LLM_MODEL` — если провайдер свой.

## Запуск

Всё сразу:

    python rewrite.py run --audio story.ogg --instruction "перепиши как полную противоположность" --out result.wav

По шагам:

    python rewrite.py transcribe --audio story.ogg --json story.json

    python rewrite.py edit --text "вставь сюда расшифровку" --instruction "перепиши как полную противоположность"

    python rewrite.py say --text "перепиши как полную противоположность" --ref story.ogg --out result.wav

Проверить без видеокарты (только расшифровка и правка):

    python rewrite.py run --audio story.ogg --instruction "перепиши как полную противоположность" --dry-run

Услышать результат без видеокарты, бесплатным синтетическим голосом
(клонирования не будет — это просто проверка, что текст звучит):

    python rewrite.py run --audio story.ogg --instruction "перепиши как полную противоположность" --engine edge --out result.wav

## Окно

Кому удобнее мышкой и с горячими клавишами — есть графический интерфейс на
wxPython: `python gui.py`. Там весь OmniVoice целиком, а не только пайплайн.

    py -m pip install wxpython

Пять вкладок: **Переписка** (запись → расшифровка → правка → синтез одним
нажатием), **Синтез** (три режима: клонирование по образцу, дизайн голоса по
описанию, авто-голос; шаги диффузии, следование тексту, темп, сохранение
голоса в `.pt`, вставка неречевых звуков), **Расшифровка** (модель, язык,
устройство, сохранение текста в файл), **Настройки** (провайдер и ключ LLM,
устройство синтеза, папка результатов) и **Справка**.

Сделано под скринридер: метка создаётся непосредственно перед своим полем
(иначе NVDA читает просто «Редактор»), списки — настоящие `wx.Choice`,
результаты и журнал — многострочные поля только для чтения, всё меню с
мнемониками по Alt. Расшифровка и синтез идут в отдельном потоке, окно не
замирает; если стоит `accessible_output3`, ключевые события проговариваются.

Горячие клавиши: `Ctrl+O` выбрать запись, `Ctrl+R` расшифровать, `Ctrl+E`
переписать, `Ctrl+S` озвучить, `F5` всё сразу, `Ctrl+Shift+S` куда сохранить,
`Ctrl+Tab` сменить вкладку, `F1` справка.

Ключ LLM во вкладке «Настройки» на диск не пишется — живёт до закрытия окна.

## Полезные ключи

`--device cuda` (по умолчанию; есть ещё `cpu`, `mps`, `xpu`) — где считать.
`--num-step 32` — шаги диффузии, больше шагов — чище и медленнее.
`--model small` — размер whisper для расшифровки (`tiny`…`large-v3`).
`--lang ru` — если автоматический язык ошибается.

## Как это работает внутри

1. Запись целиком идёт в `faster-whisper`, оттуда текст и таймкоды.
2. Из записи вырезается лучший кусок речи длиной 3–10 секунд — это образец
   голоса. OmniVoice на длинном образце клонирует хуже и считает дольше.
   Кусок и его расшифровка берутся из одного и того же места: если текст не
   совпадает со звуком, модель тянет интонацию не туда.
3. Текст уходит в языковую модель с твоей инструкцией. В системном запросе
   есть просьба писать числа словами: синтезатор читает цифры хуже.
4. Готовый текст синтезируется закодированным голосом. Длинный текст
   OmniVoice сам режет на куски примерно по пятнадцать секунд и держит память
   почти постоянной, поэтому можно отдавать хоть целую главу.

## Границы

- Клон по трём–десяти секундам: чем чище запись, тем ближе голос. Шум и
  музыка в образце утаскивают тембр.
- Образец лучше брать на том же языке, что и результат.
- Модель может пересказывать текст своими словами на длинных фразах — поэтому
  результат стоит проверять: расшифруй готовый файл тем же `transcribe` и
  сравни. Хуже всего даются аббревиатуры и редкие имена.
- Это синтез, а не правка живой записи: интонация будет ровнее оригинала.
  Инструмент, который правит уже сказанное (как Tencent AuK), на русском
  работает плохо.
